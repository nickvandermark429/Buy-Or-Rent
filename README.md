# Buy or Rent

Home purchase vs. rent decision model: compares the equity you build by buying a home with what you build by renting and investing the money you would have put down, plus each year's savings.

Live at https://nickvandermark429.github.io/Buy-Or-Rent/

The whole tool is `index.html`: one self-contained page with no build step and no server. Cases you save stay in your own browser.

For illustration only, not financial advice.
